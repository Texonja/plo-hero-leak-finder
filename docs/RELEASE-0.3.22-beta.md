# 0.3.22 beta

Download **PLO-Hero-Leak-Finder-0.3.22-beta-Windows-x64.zip** from Assets. The ZIP includes Python and Tk and runs offline without an installer. On a fresh profile the app opens HeroDemo with 644 hands and five examples for review.

GitHub’s **Code → Download ZIP** contains the source for developers. Its Windows launcher checks for Python 3.11 or later with Tk and directs players to the ready-to-run download when needed.
