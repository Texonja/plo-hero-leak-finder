# 0.3.20 beta

Open **Library → HeroDemo** to try 644 hands from CoinPoker and iPoker. The main screen highlights five decisions, each linked to its replay.

- The four new iPoker examples cover a missed squeeze with aces in the big blind, a small-blind limp-reraise with a low single-suited hand, and two costly flop calls. The existing button fold with queens is the fifth example.
- The main list counts each flagged hand once. Choose **Study spots** to explore the decisions that depend on assumptions about an opponent’s range. Advice describes relevant hand categories and gives a specific alternative when the evidence supports one.
- A startup window shows when the app is opening the library. An existing HeroDemo library picks up the four new hands automatically.
